Getting a download link

GitHub Releases hosts your file for free and gives you a permanent link. Follow these steps once — then paste the link into Auriser.

You do not need to pay for hosting. GitHub Releases is free for public repositories. The real installer stays on GitHub; Auriser only stores the link.

  1. 1. Open GitHub

    Go to github.com and sign in (or create a free account). Click Open GitHub below if you prefer a new tab.

  2. 2. Create a new repository

    Click the + in the top-right → New repository. Name it after your app (e.g. nightframe). Keep it Public — private files cannot be downloaded by other people. Click Create repository.

  3. 3. Open Releases

    Inside your new repo, find Releases in the right-hand sidebar (or go to the URL …/releases), then click Create a new release.

  4. 4. Upload your app file

    Set a version tag (e.g. v1.0.0), add a short title, then drag your built .exe / .apk / .zip / .msi into the Attach binaries box. Click Publish release.

  5. 5. Copy the file's direct link

    On the release page, right-click the uploaded file and choose Copy link address. It should look like:

    https://github.com/you/repo/releases/download/v1.0.0/YourApp.exe

    Use the full https:// link — not the Releases page URL.

  6. 6. Paste it back into Auriser

    Click Back to publishing below, then paste that link into the Download link field. Anyone who taps Download on your product page will open that file.

Tip: Windows may warn about unsigned .exe files from unknown publishers. That is normal for student builds. Sign the binary later if you want fewer SmartScreen warnings.
